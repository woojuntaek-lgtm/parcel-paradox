# 택배 역설 연구소

둘 다 이겼는데 합치면 진다? — 여러 변수를 한꺼번에 살피는 다차원 탐색을 손으로 체험하는 앱입니다. 도심·산간 모두 앞서는 A가 전체로는 지는 택배 첫 장면, 변수가 늘면 폭발하는 짝의 개수, 둘이 함께 높을 때만 터지는 결합 효과, 기온이 숨긴 교란 변수, 맡은 일의 구성을 보여 주는 막대와 같은 조건으로 맞춰 보는 비중 그래프(반반이면 A 86.5%, B 82.5%), 퀴즈 ①(광고 나 24%), 층별 분석의 주의점, 축 순서·투명도·정규화·범위 선택을 바꿔 보는 병렬 좌표계와 이상치 찾기, 선의 흐름 읽는 법, 축 순서만 바꿔도 1.8배 차이 나는 레이더 넓이와 퀴즈 ②, 단위와 겹침 함정까지 담았습니다. 빅데이터 10 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 여러 변수: 첫 장면, 짝의 개수, 결합 효과, 교란 변수
- ② 심슨 역설: 맡은 일의 구성, 같은 조건으로 맞추기, 퀴즈 ①, 쪼개 보고 맞춰 보기
- ③ 병렬 좌표: 센서 기록 병렬 좌표계(축 순서·α·정규화·범위 선택·이상치), 선의 흐름 읽는 법
- ④ 레이더: 축 순서와 넓이, 퀴즈 ②, 단위 함정, 겹침 함정, 언제 무엇을 쓸까, 코드, 세 줄 정리, 생각해 볼 질문

택배·광고 숫자(원고의 가상 예시), 결합 효과 그림(개념 그림), 아이스크림·사고, 공장 센서, 회사 지표는 모두 설명을 위한 가상 데이터입니다.
